# Wardogs Overlay — бафы и дебафы обвесов

Оверлей для игры **Wardogs**. Когда собираешь пушку у продавца (**Экипировка → Модули**),
сбоку появляется плашка: какая пушка, какие обвесы стоят и что они дают —
плюсы зелёным, минусы красным, время прицеливания в секундах.

```
 GALIL                               ШТУРМОВАЯ
 Урон 28 · 650 в/мин · Дальн. 400 м · Прицел. 0.49 с
 МАГАЗИН   Galil 35 RND Magazine
 ПРИЦЕЛ    Spitfire 3X
 РУКОЯТЬ   AFG Angled Foregrip
 Отдача вбок                      −25%
 Разброс                          −22%
 Прицел. 0,49→0,46 с              −0,03 с
 Время стабилизации               +35%
```

## Скачать и запустить

1. Открой **[Releases](../../releases)** и скачай `WardogsOverlay.zip`.
2. Распакуй (на рабочий стол или в корень диска — не глубоко в папки).
3. Запусти **`Wardogs Overlay.bat`**. При первом запуске программа сама скачает базу
   пушек, обвесов и иконки с [MetaForge](https://metaforge.app/wardogs/database) — нужен интернет.
4. В игре: режим экрана **«Оконный без рамки»**, затем **Продавец → Экипировка → Модули**.

Если Windows покажет «Система Windows защитила ваш компьютер» — «Подробнее» → «Выполнить в любом случае»
(программа самодельная и не подписана).

## Меню программы

```
  ┌──────────────────────────────────────────────────┐
  │                WARDOGS  ·  ОВЕРЛЕЙ                │
  ├──────────────────────────────────────────────────┤
  │    Поиск      ●  идёт                            │
  │    Игра       ●  найдена                         │
  │    Плашка     »  AK74 · 4 обв.                   │
  ├──────────────────────────────────────────────────┤
  │     [1] Поиск вкл/выкл      [2] Обновить базу    │
  │     [3] Настройки           [4] Журнал событий   │
  │                    [0] Выход                     │
  └──────────────────────────────────────────────────┘
```

- **Ctrl+Shift+O** — включить/выключить поиск прямо из игры. Без меню «Модули» 10 секунд — поиск засыпает.
- **[2] Обновить базу** — после патчей игры (свежие данные с MetaForge, без перезапуска).
- Подробности и все настройки — в `ИНСТРУКЦИЯ.txt`.

## Как это работает

- Снимает **только окно игры** (по процессу `WardogsClient`), OBS и другие окна не мешают.
- Находит меню по надписям «МОДУЛИ» и «ЯЧЕЙКИ ДЛЯ ЭКИПИРОВКИ» в любом масштабе —
  подходит любое разрешение (720p…4K, 16:10, 21:9, 32:9) и игра в окне.
- Название пушки и патроны («30/30») читает распознаванием текста (RapidOCR),
  обвесы узнаёт по иконкам, статы считает по точным множителям из базы MetaForge.
- **В игру не лезет**: не читает память, не меняет файлы — только смотрит на картинку, как OBS или Discord.
- Пишет подробный журнал (`app/overlay.log`) и понятный журнал событий (`app/события.txt`).

Требования: Windows 10/11 64 бит, игра на **русском** языке.

## Для разработки

```
app/wardogs_overlay.py   — сама программа (распознавание, окно поверх игры, меню)
app/update_database.py   — скачивание базы с MetaForge
app/server.py, overlay.html — плашка для OBS (по желанию: "obs_server": true)
tests/run_tests.py       — прогон по ~490 вариантам картинки (разрешения, сжатие, курсор, ловушки)
```

Нужен Python 3.12 с `numpy`, `opencv-python-headless`, `mss`, `rapidocr-onnxruntime`.

## Данные

Статы, множители и иконки — с [MetaForge](https://metaforge.app/wardogs/database), иконки — из игры Wardogs.
В репозитории их нет: программа скачивает их у каждого пользователя сама.
Проект не связан с разработчиками Wardogs и с MetaForge.
