WARDOGS ОВЕРЛЕЙ — бафы и дебафы обвесов
=======================================

Что это: когда собираешь пушку у продавца (Экипировка → МОДУЛИ), сбоку появляется плашка —
какая пушка, какие обвесы стоят и что они дают: плюсы зелёным, минусы красным,
время прицеливания — в секундах. Всё нужное уже внутри этой папки, ничего ставить не надо.

ЧТО НУЖНО
- Windows 10 или 11 (64 бит).
- Игра на РУССКОМ языке (программа ищет в меню надписи «МОДУЛИ» и «ЯЧЕЙКИ ДЛЯ ЭКИПИРОВКИ»).
- В игре: Настройки → Графика → режим экрана «Оконный без рамки» (Borderless).
  В полноэкранном режиме окно поверх игры не видно.
- Любое разрешение (720p…4K, 16:10, 21:9) и любой монитор — программа сама найдёт окно игры.

ЗАПУСК
Двойной клик по «Wardogs Overlay.bat». Откроется окно программы (его можно свернуть):

  ┌──────────────────────────────────────────────┐
  │               WARDOGS  ·  ОВЕРЛЕЙ             │
  ├──────────────────────────────────────────────┤
  │    Поиск      ●  идёт                         │   ● — работает, ○ — спит / ещё не искал
  │    Игра       ●  найдена                      │   × — не найдена (запусти Wardogs)
  │    Плашка     »  AK74 · 4 обв.                │
  ├──────────────────────────────────────────────┤
  │     [1] Поиск вкл/выкл      [2] Обновить базу │
  │     [3] Настройки           [4] Журнал событий│
  │                 [0] Выход                     │
  └──────────────────────────────────────────────┘

Чёрный фон, белые буквы. Жми просто цифру — Enter не нужен. Экран обновляется сам.
  [1] — включить/выключить поиск (Ctrl+Shift+O — то же самое прямо из игры)
  [2] — обновить базу с MetaForge, сразу начинает работать
  [3] — настройки в Блокноте: сохрани и закрой Блокнот — программа сама перезапустится с новыми
  [4] — журнал событий понятными словами (app\события.txt): какая пушка и какие обвесы узнаны,
        меню открыто/закрыто, поиск уснул, база обновлена; ⚠ — предупреждение, ✖ — ошибка
  [0] — выход. Закрыть окно крестиком — тоже выход (память сохранится).
Если Windows покажет «Система Windows защитила ваш компьютер» — «Подробнее» → «Выполнить в любом случае»
(программа самодельная, Windows её не знает).

КАК ПОЛЬЗОВАТЬСЯ
- В игре: Продавец → Экипировка → МОДУЛИ. Через секунду справа появится плашка.
  Ушёл в другое меню — плашка спряталась.
- Если меню «Модули» не видно 10 секунд — поиск «засыпает» и не тратит процессор.
  Ctrl+Shift+O в игре (или 1 в меню) — снова включить.
- Плашка меняется, только когда два снимка подряд показали одно и то же — поэтому не мигает.

ОБНОВЛЕНИЕ БАЗЫ (после патчей игры)
Пункт 2 в меню. Скачивает свежие данные с metaforge.app (точные множители из файлов игры,
баллистика Season 2), пишет в app\update_database.log, что изменилось, докачивает иконки новых
обвесов, старую базу сохраняет как app\wardogs_data.prev.js. Сразу начинает работать, перезапуск не нужен.
Если сайт отдаст что-то странное — база не меняется.

НАСТРОЙКИ — app\settings.json ([3] в меню; после сохранения программа сама применит)
  "hotkey"           — горячая клавиша вкл/выкл поиска, например "Ctrl+Shift+O", "Alt+F9"
  "auto_off_seconds" — через сколько секунд без меню поиск засыпает (0 — никогда)
  "confirm_frames"   — сколько снимков подряд должны совпасть, чтобы плашка поменялась (2)
  "x", "y"           — "auto": плашка встаёт рядом с меню. Или числа — пиксели на экране
  "monitor"          — "auto": смотреть только окно игры. Номер 1, 2, 3… — весь монитор (запасной вариант)
  "opacity"          — прозрачность плашки (1 = непрозрачная)
  "show_window"      — false — не показывать плашку поверх игры (только для OBS)
  "obs_server"       — true — плашка для OBS: источник «Браузер» → http://127.0.0.1:8777/overlay.html (1920×1080)
  "log_level"        — подробность журнала: "DEBUG" / "INFO" / "WARNING"

ЖУРНАЛ И ЕСЛИ ЧТО-ТО НЕ ТАК
Кроме журнала событий, программа всегда пишет подробный технический журнал app\overlay.log: нашла ли окно игры,
где меню, что прочитала, какой обвес узнала и с какой точностью, все ошибки. Больше 5 МБ —
старый журнал становится overlay.log.1.
- Пушка не узнаётся → её название из игры попадёт в app\unknown_names.txt.
- Меню «почти нашлось», но не дотянуло → сохранится картинка app\debug_miss.jpg.
Пришли overlay.log (и debug_miss.jpg, если есть) — по ним видно, в чём дело.

ПРОВЕРКА ПОСЛЕ ИЗМЕНЕНИЙ (для разработки, в архив для друзей не входит)
tests\run_tests.py — прогон по ~440 вариантам картинки: разрешения 720p…4K, 16:10, 21:9, 32:9, игра в окне,
масштаб интерфейса, сжатие, размытие, яркость/гамма, «Ночной свет», шум, курсор, ловушки без меню.
Запуск: python\python.exe -I tests\run_tests.py   Итог — tests\report.txt (~15 минут).

ЭТО БЕЗОПАСНО?
Программа только делает снимки окна игры и рисует своё окно (как Discord или счётчик FPS).
В игру не лезет, память игры не читает, файлы игры не трогает.

ПАПКИ
  Wardogs Overlay.bat   — запуск
  python\               — Python только для оверлея
  app\                  — программа: wardogs_overlay.py (сама программа), update_database.py (обновление базы),
                          server.py + overlay.html (плашка для OBS), wardogs_data.js + icons.json + icons\ (база),
                          ref_*.png (образцы надписей меню), settings.json, recognition_cache.json (память),
                          overlay.log (журнал)
